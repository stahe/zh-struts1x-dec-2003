    6. 表单 HTML

    迄今为止，我们仅使用了一个包含两个输入字段的表单。在此，我们将尝试创建并处理一个使用常用图形组件（单选按钮、复选框、输入字段、下拉列表、列表）的表单。

    6.2. 应用程序架构

    • 表单（视图 1）将由一个名为 dynaFormulaire 的动态 Struts 对象表示，该对象的类型继承自 DynaActionForm。它将通过视图 formulaire.jsp 进行显示。

    6.3.4. 应用程序的表单对象（Beans）

    用于表示应用程序中 HTML 表单的对象，是 ActionForm 类型或其派生类型（如 DynaActionForm、DynaValidatorForm 等）的对象。 之所以称其为 Bean，是因为它们的构造遵循 JavaBeans 的规则。我们的应用程序中仅有一个表单 Bean，名为 dynaFormulaire，其类型是从 DynaActionForm 派生而来的。它将在以下情况下使用：

    • 包含显示视图 1 所需的数据
    • 在用户提交（submit）表单时，从视图 1 中获取表单值
    • 包含显示视图 2 所需的数据

    6.3.5. 应用程序的动作

    操作由 Action 类型或其派生类型的对象负责。操作的配置在 <action-mappings> 标签内进行：

        <action-mappings>
      <action
          path="/confirmation"
            name="dynaFormulaire"
            validate="false" 
            scope="session"
          parameter="/vues/confirmation.jsp"
          type="org.apache.struts.actions.ForwardAction"
      />

      <action
          path="/init"
            name="dynaFormulaire"
            validate="false" 
            scope="session"
          type="istia.st.struts.formulaire.InitFormulaireAction"
      >
            <forward name="afficherFormulaire" path="/vues/formulaire.jsp"/>
        </action>

      <action
          path="/affiche"
          parameter="/vues/formulaire.jsp"
          type="org.apache.struts.actions.ForwardAction"
      />

    </action-mappings>

    需要注意的是，并非所有操作都关联着表单。上文中的 /affiche 操作便是如此。在详细介绍每个操作之前，让我们回顾一下 <action> 标签内操作与表单这对组合的工作原理：

    • 一个操作始于 Web 客户端的请求，终于响应页面的发送。这就是 Web 客户端与服务器之间的请求-响应循环。请求由类型为 ActionServlet 或其派生的 Struts 控制器接收。该控制器也会发送响应。
    • 如果尚未存在，则会创建类型为 ActionForm 或其派生类的表单 Bean。控制器会检查是否能在 scope 指定的作用域中找到名为 name 的对象。如果存在，则直接使用该对象；如果不存在，则创建该对象并将其放入 scope 指定的作用域中，同时将其与 name 指定的属性关联起来。

    例如在 /init 操作中，控制器将执行 request.getSession().getAttribute("dynaFormulaire") 来判断 dynaFormulaire 是否已被创建。 如果尚未创建，它将创建该对象，并通过类似 request.getSession() 的语句将其放入会话中。setAttribute("dynaFormulaire",new DynaFormulaire(...))。

    • 控制器还将查找类型属性指定的Action对象。若未找到，则创建该对象；否则直接使用现有对象。
    • 表单 Bean 的 reset 方法将被调用。该 Bean 除初始创建时外，均会被回收利用。因此其中可能包含需要“清理”的数据。这将在 ActionForm Bean 或其派生类的 reset 方法中进行。
    • 如果该操作是表单提交的目标，则客户端请求中包含的表单值会被复制到表单Bean中同名的字段中。需要注意的是，在此复制操作之前已调用了reset方法。
    • 如果配置中指定了 validate="true" 属性，则会调用表单 Bean 的 validate 方法。该方法必须对 Bean 中的数据进行验证。 这种验证通常仅在表单刚通过 POST 请求接收新数据，且需要验证这些数据有效性时进行。该方法会将可能的错误列表以 ActionErrors 对象的形式返回给控制器。
    • 如果 ActionErrors 对象不为空，控制器将显示由操作的 input 属性指定的视图。
    • 如果未要求进行数据验证，或者验证成功，控制器将执行与当前操作关联的 Action 类型对象或其派生对象的 execute 方法。Web 客户端的请求将在该方法中得到处理。execute 方法返回一个由字符串类型键索引的 ActionForward 对象。 这些键由已配置操作的 forward 标签声明。在本例中，操作 /init 仅有一个 forward 标签。它将键 "afficherFormulaire" 与视图 formulaire.jsp 关联。
    • 控制器会显示与接收到的键关联的视图。该视图实际上可能是一个操作，在这种情况下，上述过程将重复进行。

    /init 操作

            <action
          path="/init"
            name="dynaFormulaire"
            validate="false" 
            scope="session"
          type="istia.st.struts.formulaire.InitFormulaireAction"
      >
            <forward name="afficherFormulaire" path="/vues/formulaire.jsp"/>
        </action>
    • /init 操作通常在第一次请求-响应循环中发生一次，即当用户请求 URL 时http://localhost:8080/formulaire2/init.do
    • 对象 dynaFormulaire 被创建或回收。根据 scope 属性的要求，该对象会被取回（回收）或放入（创建）会话中。
    • 其 reset 方法被调用。该方法应执行什么操作？通常情况下，我们会将 ActionForm 对象的字段重置为默认值。但在此处，我们不会这样做，因为 dynaFormulaire 对象被放置在会话中（scope="session"）。 因此，dynaFormulaire 的字段必须保留其值。在初始创建 dynaFormulaire 对象时，这些值是什么？有两种情况：

    在此情况下，Struts 控制器将使用该初始值创建该字段。

    • 该字段在配置中未指定初始值：此时将应用 Java 的初始化规则。通常，数值型字段的初始值为零，字符串型字段的初始值为空字符串，其他对象的初始值为 null。

    • 未勾选 chk1 复选框。此时浏览器不会发送 chk1 字段的值，该字段将保持其之前的“off”值。在两种情况下，dynaFormulaire 中 chk1 字段记录的值都是正确的。

    6.5.1. 类 DynaFormulaire

    要存储表单的值，一个 DynaActionForm 类型的对象就足够了，除非需要重写该类的 reset 或 validate 方法之一。在此处，由于不进行任何数据验证，因此无需重写 validate 方法。 但 reset 方法则需要重写。实际上，DynaFormulaire 对象的字段将从 Web 客户端提交的表单中获取其值。然而，如果某些字段未出现在请求中，它们可能无法获取值。这种情况发生在以下情形中：

    • 用户未勾选的复选框
    • 下拉列表中选项数量超过1个，或未选中任何选项

    对于包含此类组件的表单，reset 方法必须

    • 将与该复选框关联的字段值设为“off”
    • 将空字符串赋值给与单选列表关联的字段
    • 将一个大小为零的字符串数组赋值给与多选列表关联的字段

    因此，如果这些字段未从请求中接收值，它们将保留由 reset 赋值的值，该值对应于用户提交表单时组件的状态（复选框未勾选，列表中未选中任何项目）。

    类 DynaFormulaire（该类继承自 DynaActionForm）的代码如下：

    package istia.st.struts.formulaire;

import org.apache.struts.action.DynaActionForm;
import org.apache.struts.action.ActionMapping;
import javax.servlet.http.HttpServletRequest;

public class DynaFormulaire extends DynaActionForm {
  public void reset(ActionMapping mapping, HttpServletRequest request){
    // 复选框重置 - 值为 off
    set("chk1","off");
    set("chk2","off");
    set("chk2","off");
    // 重置 listeSimple - 空字符串
    set("listeSimple","");
     // 重置 listeMultiple - 空数组
    set("listeMultiple",new String[]{});
  }
}

    在文件 struts-config.xml 中，类 InitFormulaireAction 与操作 /init 相关联：

    /init 操作仅在初始化 DynaFormulaire 对象时使用一次。其目的是为下拉列表表单的三个列表（listeSimple、listeMultiple）提供内容。 该内容以三个数组的形式提供，这些数组是 dynaFormulaire 对象的属性：

    一旦 valeursCombo、valeursListeSimple、valeursListeMultiple 这几个数组被 InitFormulaireAction 初始化后，就不再需要再次初始化。 这是因为对象 dynaFormulaire 被放置在会话中，因此在请求-响应循环中会保留其值。这就是为什么 /init 操作仅执行一次。InitFormulaireAction 的代码如下：

    package istia.st.struts.formulaire;

import java.io.*;
import javax.servlet.*;
import javax.servlet.http.*;
import org.apache.struts.action.*;

public class InitFormulaireAction
  extends Action {
  public ActionForward execute(ActionMapping mapping, ActionForm form,
       HttpServletRequest request, HttpServletResponse response) throws IOException,    ServletException {

     // 准备显示表单

     // 将表单所需的信息放入其 Bean 中
    DynaFormulaire formulaire = (DynaFormulaire) form;
    formulaire.set("valeursCombo", getValeurs(5, "combo"));
    formulaire.set("valeursListeSimple", getValeurs(7, "simple"));
    formulaire.set("valeursListeMultiple", getValeurs(10, "multiple"));
     // 控制权交还
    return mapping.findForward("afficherFormulaire");
  } //执行

   // 下拉列表的值列表
  private String[] getValeurs(int taille, String label) {
    String[] valeurs = new String[taille];
    for (int i = 0; i < taille; i++) {
      valeurs[i] = label + i;
    }
    return valeurs;
  }
}
    • 该类继承自Action类。这是强制要求的。
    • Struts控制器通过其execute方法使用Action对象。因此需要重写该方法。该方法接收以下参数：
      • ActionMapping mapping：一个表示应用程序配置的对象，位于struts-config.xml
      • ActionForm form：与该操作关联的表单（如果操作配置中定义了表单，则通过操作的 name 属性获取）。
      • HttpServletRequest request：客户端的请求
      • HttpServletResponse：对客户端的响应
    • 类 InitFormulaireAction 必须初始化表单 dynaFormulaire。该表单以参数 ActionForm form 的形式传递给 execute 方法。 需要说明的是，dynaFormulaire 属于 DynaFormulaire 类型，该类是从 DynaActionForm 类派生而来的，而 DynaActionForm 类本身又是从 ActionForm 类派生而来的。
    • 在 execute 方法中，通过 DynaActionForm 类的 set 方法，为三个字段 valeursCombo、valeursListeSimple、valeursListeMultiple 赋值。 为简化起见，这些值是任意的数组。需要注意的是，set方法仅用于为现有字段赋值，无法用于创建新字段。因此，必须在valeursCombo、 valeursListeSimple、valeursListeMultiple。
    • execute方法结束时，会将要显示给客户端的视图键作为响应返回给控制器。在此，afficherFormulaire键在文件struts-config.xml中已被关联到视图/vues/formulaire.jsp。
